You need [composer](https://getcomposer.org/), `laravel`, installed via [composer](https://getcomposer.org/), [php](https://www.php.net/) and [npm](https://www.npmjs.com/) installed to run this app.

```
git clone https://github.com/user-with-avatar/laravel-crud-template
cd laravel-crud-template
composer install
npm i
cp .env.example .env
```
for windows use 'copy' instead of 'cp'
```
php artisan migrate
composer run dev
```
